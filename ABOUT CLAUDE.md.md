What's a CLAUDE.md? And what if I'm not using Claude?



## What's a CLAUDE.md?



CLAUDE.md is a plain text file you put in your project folder. When you start a session with Claude, it reads this file first — before you say anything.



Think of it as a note you leave on the desk for your collaborator before they sit down: who you are, what you're working on, how you like to communicate.



It's not code. It's not configuration. It's just a markdown file — the same format as a README. You write in plain English, and your AI treats it as standing instructions.



## I'm not using Claude



Other AI tools have their own version of this. ChatGPT has project instructions. Gemini has context files. The concept is the same: give your AI something to read before the conversation starts, so you don't have to repeat yourself every session.



## How to Use



The vault template includes a starter CLAUDE.md with fill-in-the-blank sections. You don't need to be technical to use it — if you can write a grocery list, you can write a CLAUDE.md.
