I prefer 2-space indentation, single quotes in JavaScript, and no semicolons unless required. When writing Python, use f-strings not .format().

**Why:** I learned on these conventions and they're what I read fastest. My AI kept defaulting to 4-space tabs until I put this here.

**How to apply:** Any time you write or edit code in this project, follow these conventions without asking.
